how does the "-t" switch work?

GPT-5 mini:
-t specifies the archive type (format) for create/extract/list operations.

Syntax
- -t{type}
- Example: -tzip, -t7z, -tgzip, -tbzip2, -ttar

Behavior
- When creating (a): selects the output archive format (e.g., -tzip makes a .zip; -t7z makes .7z).
- When listing/extracting (l/x/e): forces 7-Zip to treat the input as that format (useful if extension is wrong).
- For formats that support streams (gzip, bzip2): 7-Zip writes a single-file compressed stream (useful with -si/-so).
- If format is incompatible with some switches, 7‑Zip will error (e.g., -v split with some stream formats).

Common types
- 7z — native 7z format (supports solid, compression options)
- zip — widely compatible ZIP
- gzip — single-file stream (.gz)
- bzip2 — single-file stream (.bz2)
- tar — container only (use with -so/-si or piped to gzip)
- xz — single-file stream (.xz)

Examples
- Create a ZIP:
  & "C:\Program Files\7-Zip\7z.exe" a -tzip ".\out.zip" files\*
- Create a 7z:
  & "C:\Program Files\7-Zip\7z.exe" a -t7z ".\out.7z" files\*
- Force extraction as tar:
  & "C:\Program Files\7-Zip\7z.exe" x -ttar archive   # treats archive as TAR regardless of name
- Create gzip from stdin (single file):
  & "C:\Program Files\7-Zip\7z.exe" a -tgzip -si"file.txt" "file.txt.gz"

Notes
- If you omit -t, 7-Zip infers format from the output filename or input data.
- Some formats (zip) don’t support all 7z-specific options (solid blocks, some filters).
- Use -bb3 for detailed output when diagnosing format-related errors.

// Generator: yield file paths (non-recursive) in srcFolder excluding our output directories.
function* listFiles(folder) {
  const dir = fs.opendirSync(folder);
  try {
    let d;
    while ((d = dir.readSync()) !== null) {
      if (!d.isFile()) continue;
      const full = path.join(folder, d.name);
      const rel = path.relative(folder, full);
      if (rel.startsWith('exe' + path.sep) || rel.startsWith('7z' + path.sep)) continue;
      yield full;
    }
  } finally {
    dir.closeSync();
  }
}
