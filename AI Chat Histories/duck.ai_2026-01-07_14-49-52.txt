## Using NodeGUI for a Simple Local JavaScript Program

- Create a new folder for your project (e.g., `C:\MyNodeGUIApp`).
- Inside this folder, create a new text file and rename it `app.js`. This will be your JavaScript file.

### 3. Include NodeGUI

- In this folder, create another folder called `node_modules`. You can manually download the NodeGUI package or copy it from an existing installation.
- Make sure to include any necessary DLLs in your project folder.

### 4. Write Your JavaScript Code

Open `app.js` in Notepad or any text editor and write a simple program. Below is an example code that creates a window displaying a PNG file and some text:

```javascript
const { app, QMainWindow, QWidget, QLabel, QPixmap } = require("@nodegui/nodegui");

const win = new QMainWindow();
win.setWindowTitle("Simple NodeGUI App");
win.setGeometry(100, 100, 300, 200);

const centralWidget = new QWidget();
win.setCentralWidget(centralWidget);

const label = new QLabel();
label.setText("Hello, World!");
label.setPixmap(new QPixmap("path/to/image.png")); // Make sure the path is correct

centralWidget.addWidget(label);

win.show();

app.exec();
```
